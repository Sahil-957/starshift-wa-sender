Campaigns

Chatbot auto-replies*

When a customer's message matches the welcome keywords or a rule, the bot replies automatically. With the server WhatsApp linked (top right) the reply goes from the server the moment the message arrives; otherwise it goes from your WhatsApp Web tab. Groups are ignored and each message is answered only once.

Welcome menu

Sent when a customer greets you. Clear the keywords to turn it off.

For a customer the bot has answered in the last 24 hours: whatever they send - even "ok", a sticker or a photo - gets a reply, the menu again when nothing else matches. Chats that never talked to the bot get nothing.

Keyword rules

Checked top to bottom; the first match replies. Put several keywords in one rule with commas. Contains matches whole words ("hi" never fires on "this"); a number keyword such as a menu option 1 must always be the whole message.

STOP / Unsubscribe

An unsubscribed contact gets no chatbot replies until they send a START keyword - that takes them off the Unsubscribers list and sends the welcome menu. Keywords from campaign unsubscribe footers always work, even with the chatbot off.

Test reply

Type what a customer might send to see the reply the bot would pick. Nothing is sent.

* Conditions apply: the chatbot works only while WhatsApp Web is open and logged in in this Chrome, answers one-to-one chats only, pauses during campaigns, and replies from your own WhatsApp number - so follow WhatsApp's Business and Commerce policies. WhatsApp Web updates can occasionally interrupt auto-replies.

Quick replies

Saved answers for common questions, prices, catalog or support steps. On WhatsApp Web, open a chat and click the green ⚡ button (bottom right) to insert one into the message box.
